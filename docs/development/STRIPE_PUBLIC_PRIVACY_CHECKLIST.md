# Stripe Public Privacy Checklist

Complete manually in Stripe Test Mode before any Live Mode activation. Record screenshots or
review notes in a private operations system; do not commit customer or owner personal data.

- [x] Checkout shows `AXIS` / `AXIS Membership`, neutral product copy, and no private identity.
- [ ] Payment confirmation shows no private name, email, address, Discord profile, or biography.
- [ ] Receipt uses AXIS brand support information and no personal support email.
- [ ] Invoice product, memo, footer, and support fields contain no private identity.
- [ ] Customer Portal branding, support link, return link, and cancellation screen use AXIS.
- [ ] Statement descriptor is an allowed AXIS variant and has been verified on a test charge.
- [ ] Stripe Business Profile display name is AXIS where Stripe permits it.
- [ ] A dedicated AXIS support email is configured; no personal email is customer-facing.
- [ ] Metadata visible to customers contains no owner ID, private notes, or personal contact data.
- [ ] Checkout, Portal, receipt, invoice, cancellation, and confirmation screenshots were reviewed.
- [ ] Any identity Stripe legally requires is documented without falsification or attempted bypass.

This checklist does not bypass Stripe KYC, legal-entity, tax, or merchant disclosure requirements.
