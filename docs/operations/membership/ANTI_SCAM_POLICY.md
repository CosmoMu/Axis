# AXIS Anti-Scam Policy

Welcome must always tell Newcomers that AXIS staff will never DM first requesting private payment,
crypto transfers, passwords, brokerage credentials, or remote account access.

Official payments are available only through the official AXIS Membership flow after permanent
approval. Newcomer channel permissions and both current/legacy checkout services enforce approval
server-side, so a copied URL or old component cannot bypass the gate.

Managers should FLAG uncertain applications for review. REJECT does not automatically ban. Use a
separate Discord kick/ban only for confirmed malicious behavior, impersonation, scam or spam.
Report suspected impersonation in `🚨・system-alerts`; the Manager remains the final decision maker.
