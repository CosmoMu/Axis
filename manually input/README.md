# 手动资料收件箱

这里是新想法、截图、草稿和外部资料的临时入口，不是长期文档目录。

Codex 处理顺序：

1. 判断资料属于产品规格、开发计划、运维、架构决策还是图片资源。
2. 将有效内容合并到对应的正式文档，或把资源移动到 `assets/` 的对应目录。
3. 在涉及需求变化时同步更新验收清单和 Discord Blueprint。
4. 确认内容已完整吸收后，删除重复副本、临时导出物和无长期价值的中间文件。

不会自动删除以下资料：

- 尚未理解或存在歧义的原始资料；
- 唯一来源文件；
- 可能包含尚未完成决策的信息；
- Secret、个人信息或交易输入原图。这些内容会先停止处理并提示安全处置。

请不要把 Bot Token、API Key、数据库密码或其他 Secret 放进这个目录。
