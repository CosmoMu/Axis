# AXIS 图片资源索引

唯一正式 Logo 为 `assets/axis-brand-lockup.png`，依次显示 AXIS 图标、`A X I S` 和
`Signals without the noise.`。Discord Server Avatar、Bot Avatar、欢迎页和其他品牌位
都统一使用这张图片。

这个路径必须保持稳定。任何正式资产都不得重新出现旧品牌名称，也不得改用自动生成的
替代 Logo。

后续图片请按用途上传：

- Logo、配色样例和品牌变体：`assets/brand/`
- Discord 欢迎页、订阅页和卡片使用的正式图片：`assets/discord/`
- 仅供开发对照的截图或设计参考：`assets/references/`

文件名使用小写英文和连字符，例如 `welcome-banner-v2.png`。不要把 Discord 用户截图、
原始交易输入图片、Token、二维码密钥或其他敏感资料提交到 Git；这类临时输入应通过
Discord 私有输入频道处理，而不是放进本目录。

视觉继续使用接近纯黑背景、白色或米白色主文字，以及少量低饱和薄荷绿。绿色只作为
中轴、触发点、按钮或关键状态强调；不使用大面积绿色、渐变或霓虹效果。
