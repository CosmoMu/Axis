# AXIS 图片资源目录

`assets/axis-logo.png` 是当前唯一正式 AXIS Logo。它与原始
`axis-brand-lockup` 资产内容一致；Discord Server Avatar / Bot Avatar 只取其中的
AXIS 图标版本，不使用自动生成的替代 Logo。

以后图片按用途放置：

- 品牌 Logo、Avatar、Lockup：`assets/`，文件名使用 `axis-用途.扩展名`。
- 开发文档截图与流程图：`assets/docs/`。
- UI 设计稿与审核参考：`assets/design/`。
- 临时想法图片：先放 `manually input/`，吸收后由 Codex 分配到上述目录。

不要把交易输入原图、Secret、个人信息、带签名 URL 或生产附件归档到本目录。
